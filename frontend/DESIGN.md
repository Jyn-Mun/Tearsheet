# DESIGN.md — Tearsheet terminal (UI source of truth)

> Read this in full before any UI work. This is the difference between "looks designed" and
> "looks generated". The aesthetic is a **deliberate point of view executed with precision**, not
> decoration. Commit fully.

## Aesthetic direction
**"Analyst terminal."** Dark, data-dense, high-contrast, restrained, precise. A refined modern take
on a Bloomberg/terminal instrument. Density is a feature, not a bug — but density with rigorous
alignment and hierarchy, not clutter. The thing a viewer should remember: *it looks like a real
tool, not a chatbot with a skin.*

## Hard rules (FORBIDDEN — these are the AI-slop tells)
- ❌ No purple/violet gradients on white. No pastel "friendly fintech" palette.
- ❌ No Inter, Roboto, Arial, system-ui, or Space Grotesk as the primary face.
- ❌ No rounded pastel cards, no drop-shadow "floating card" soup, no emoji.
- ❌ No bouncy/spring animations, no confetti, no gratuitous micro-interactions.
- ❌ No evenly-distributed rainbow palette. One dominant base + sharp semantic accents only.

## Colour tokens (CSS variables — single source of truth)
```css
:root {
  --bg:         #0B0E14;  /* near-black charcoal base */
  --panel:      #141925;  /* elevated module surface */
  --border:     #222A38;  /* hairline borders */
  --text:       #E6E8EB;  /* high-contrast off-white */
  --text-muted: #8B93A1;  /* secondary text */
  --up:         #3FB950;  /* gains — green (financial convention) */
  --down:       #F85149;  /* losses — red */
  --accent:     #E8B339;  /* single amber accent: "live"/active only */
}
```
Dominant dark + one sharp accent beats a spread-out palette. Green-up / red-down is the financial
convention — use it for deltas only, never as decoration.

## Typography (the single biggest credibility signal)
- **Display / headings:** Mona Sans or Hubot Sans (GitHub's industrial grotesques).
- **Body / UI:** Geist or IBM Plex Sans — clean, *not* Inter.
- **All numbers, tickers, prices, timestamps:** a monospace with **tabular figures** — JetBrains
  Mono, IBM Plex Mono, or Geist Mono, with `font-variant-numeric: tabular-nums;`.
- Load via Fontsource or Google Fonts (all free/open). **Do not skip the tabular-nums monospace for
  numerics** — it is the strongest "serious tool, not generated" signal.

## Layout & detail
- **Left rail:** ticker search + recent lookups.
- **Main area:** stacked, hairline-bordered modules
  (Snapshot · Price+sparkline · Financials · Valuation · DCF · Bull · Bear/Risks · News · Sources).
- Hierarchy by weight: the headline number (price / key metric) large + bold mono; secondary
  metrics small + muted.
- **Right-align all numeric columns; tabular numerals so digits line up vertically.**
- A small sparkline / simple candlestick for price (lightweight chart lib — e.g. `lightweight-charts`
  or small SVG; not a heavy dashboard kit).
- **Motion:** exactly ONE restrained staggered reveal on load (modules fade/translate in ~40ms
  apart). Nothing else. Crisp = credible.
- **Footer:** monospace, muted, intentional — like a terminal status line. Provenance +
  "not financial advice" + timestamp:
  `Generated by AI from public sources · research tool, not financial advice · {timestamp}`.

## Definition of done (UI)
- Passes the FORBIDDEN-list check above.
- Numerics are mono + tabular + right-aligned everywhere.
- One staggered load reveal, nothing else moving.
- Footer disclaimer present and styled as a terminal status line.
